# CoreXeno

CoreXeno enables distributed real-time processing and auto-scaling on a unified, cross-platform server system architecture.

The key benefits of using CoreXeno include:

- CoreXeno enables distributed real-time processing
- and auto-scaling on a unified,
- cross-platform server system architecture

## Technology Stack

- javascript

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/CoreXeno.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

CoreXeno is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
